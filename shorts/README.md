# shorts/ — вертикальные клипы 9:16 из готовых инфографик (H4265 pilot)

_Created: 06-09-2026 · H4265 (OxAlpha) — видео-пилот S5-of-5 из зонтика H4260 «Наглядность-2026»_

Детерминированный рендер вертикальных shorts (Reels/Shorts/VK-клипы) из
storyboard-страниц: каждый клип — самодостаточная страница 1080×1920, где
**вся анимация — чистая функция времени** `window.__seek(t)` (никаких CSS-таймеров),
поэтому кадры воспроизводимы байт-в-байт при перерендере.

## Контракт пилота (H4265)

- Готовые mp4 — **локально** в `dist/shorts/` (gitignored). В git коммитятся только шаблоны.
- Субтитры RU, без жаргона (для холодной аудитории): вшиты в кадр + `.srt` сайдкар рядом с mp4.
- Kill-gate: если 9:16 не собирается за 3 итерации — STOP с докладом. (Не сработал: рендер собирается, см. `docs/` отчёт пилота.)

## Запуск

```sh
npm install --prefix tools          # один раз (puppeteer)
node shorts/render_short.js pilot-01-five-encodings pilot-02-sandhi pilot-03-gita-coverage
# опции: --fps 30 · --out dist/shorts · --quality 92 · --keep-frames
```

Chrome: берётся `PUPPETEER_EXECUTABLE_PATH`, иначе системный Chrome
(скачанный "Chrome for Testing" macOS Gatekeeper убивает — fallback встроен).

## Как добавить новый клип

1. Скопируй любой `clips/pilot-*/index.html` как шаблон.
2. Опиши сцены; весь кадр — из `window.__seek(t)`; каптции — массив `CAPTIONS`
   (`{t0, t1, text}`), рендерер сам соберёт `.srt`.
3. `window.__meta = { id, title, duration, captions }`.
